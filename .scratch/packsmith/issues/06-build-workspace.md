# 06: 打包（一）：分支选择与临时工作区

**What to build:** 项目详情的打包入口：发起打包时实时用 `git ls-remote` 拉取远程分支列表供下拉选择（记住该项目上次选择的分支），随后自动创建临时工作区并 clone 选定分支。本票结束时：用户选分支 → 代码在临时工作区就绪，尚不构建。临时工作区位于系统临时目录、由 Packsmith 统一管理。

**Blocked by:** 03, 05

**Status:** resolved

- [ ] 分支列表为实时拉取（远程新建分支可见），默认选中该项目上次用的分支
- [ ] 临时工作区自动创建，指定分支代码完整
- [ ] 无效分支名/网络失败有明确错误，临时工作区被清理
