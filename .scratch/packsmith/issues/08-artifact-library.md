# 08: 构件库与构建历史

**What to build:** 构建成功后扫描 target 产物：单个 jar/war 自动选中，多个时用户勾选（选择结果记为该项目默认）；选中构件在删除临时目录前复制进产物库 `<appdata>/artifacts/<项目>/<构建时间>/`。构建历史列表（项目/分支/时间/结果）+ 历史日志查看 + 产物库保留策略（保留最近 N 次）与手动清理。全程用户本地 `~/.m2` 零污染（ADR-0001 验收）。
