# 09: 部署目标配置

**What to build:** "部署目标"领域实体落地（项目 × 服务器的绑定）：为项目配置一个或多个部署目标，每个携带：服务器（从 04 的列表选）、上传目录、启动命令组、停止命令组（命令组 = 多行命令编辑器，如 `cd /home/app \n sh start.sh start`）。CRUD 入加密库。命令的执行不在本票。

**Blocked by:** 04, 05

**Status:** resolved

- [ ] 可为项目创建/编辑/删除部署目标
- [ ] 上传目录与两个命令组均多行编辑，保存后回显正确
- [ ] 同一项目可绑定多台服务器，同一服务器可被多个项目绑定
- [ ] 数据入加密库，重启后仍在
