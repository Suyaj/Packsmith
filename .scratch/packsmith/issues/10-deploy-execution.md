# 10: 部署执行：上传 + 命令组重启

**What to build:** 构建完成页对选定部署目标（可多选）点"部署"：SFTP 将选中构件以原文件名覆盖上传到目标上传目录 → 执行停止命令组（多命令按序串行、以 SSH 登录用户身份）→ 停止成功则执行启动命令组；停止失败则中止重启、明确展示停止阶段的错误输出，由用户判断，并提供"单独执行启动命令组"操作。执行输出快照可查看。每个部署目标有"构建成功后自动连锁部署"开关，默认关。

**Blocked by:** 08, 09

**Status:** ready-for-agent

- [ ] 部署后服务器上传目录出现同名新构件（覆盖旧文件）
- [ ] 重启走通：停止 → 启动，两阶段输出均可见
- [ ] 停止命令组失败：不执行启动，错误展示明确，可手动单独执行启动
- [ ] 多个部署目标可一次操作依次部署
- [ ] 自动连锁开关默认关，打开后构建成功自动触发该目标部署
