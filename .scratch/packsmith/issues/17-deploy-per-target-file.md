# 17: 部署目标与构建产物一一对应上传

**What to build:** 部署对话框改为**按部署目标逐个选择文件**：对一次构建（构建历史条目），每个选中的部署目标各自从该次构建的产物列表中选择要上传的文件（单产物自动选中；多产物默认记住上次该目标的选择），上传时只传各自选中的那一个文件到该目标的上传目录——**绝不把产物库里本次构建的全部文件都传上去**。原文件名覆盖、进度、停止→启动编排、取消等行为全部不变。

**Blocked by:** None（基于集成 tip）

**Status:** ready-for-agent

- [ ] 部署对话框：每个目标一行，行内从本次构建产物列表选文件（默认单产物自动选中/记忆上次）
- [ ] 多个目标可各选不同文件，一一对应上传（原文件名覆盖语义不变）
- [ ] 未被任何目标选中的文件不上传（测试断言上传调用集合 = 选中集合）
- [ ] 停止→启动编排、停止失败中止、取消、进度展示全部不回退（既有测试仍绿）
- [ ] 前端测试：逐目标选择、默认值、提交 payload 中每个目标对应正确文件
