# 21: 构件选择器支持搜索与多选

**What to build:** 打包面板构建成功后的构件选择器（现为 radio 单选、仅 >1 个产物时出现）改为**可搜索多选**：cmdk Combobox（与打包分支选择器同款交互，模糊过滤），可勾选多个构件。多选结果保存为项目的**默认构件列表**；部署对话框空名行补选的预选、自动连锁的取用顺序都按该列表从头到尾依序使用。单选行为不回退：只勾一个时行为与现在的"默认构件"一致。

**语义细节：**
- 存储：迁移 v13，项目级默认构件列表（新子表或 JSON 列）；迁移时把既有单值 `default_artifact`（非空）回填为单元素列表；原列保留但废弃（与票 19 的 `upload_dir` 同法）
- 空列表 = 未设置（与现在"未保存默认构件"一致）
- 列表顺序即勾选顺序（或列表显示顺序），补选/自动连锁按序取用，用尽后回退首个可用产物
- UI：多选 Combobox 显示已勾选集与当前产物集；"保存默认构件"按钮不变；i18n 中文

**Blocked by:** None（基于集成 tip df8d613）

**Status:** resolved

> 实现（TDD，三个切片提交）：
> - **存储**（迁移 v13）：新子表 `project_default_artifacts(id, project_id FK 级联, file_name, position)`；既有非空单值 `projects.default_artifact` 回填为单元素列表（空白不回填）；原列保留但废弃（与票 19 的 `upload_dir` 同法）。`Project.default_artifact` → `default_artifacts: Vec<String>`（有序，空列表 = 未设置）。
> - **保存**：`set_default_artifacts` 命令整组原子替换，空列表 = 清除选择，空构件名拒绝（稳定 code `invalid_artifact`）；单构件构建仍自动记住（单元素列表），多构件不自动改默认（票 08 语义不回退）。
> - **取用顺序**：自动连锁的空名行（原票 19 一律跳过）现按项目默认列表**依序**取第一个本次构建可用的构件，列表用尽回退首个可用产物（按文件名序）；空列表 = 未设置，照旧跳过并提示。手动部署路径不变（对话框补选优先，strict 兜底校验照旧）；部署对话框空名行预选同样按列表依序取第一个可用项，用尽回退首个产物。
> - **前端**：构件选择器 radio 单选改为 cmdk 可搜索多选 Combobox（与分支选择器同款模糊过滤/命中高亮，勾选不下拉不收起），单/多产物场景均可用；触发按钮回显已勾选集；「保存默认构件」按钮不变，按勾选顺序保存。中文 i18n、GLOSSARY「默认构件列表」词条。
