# 24: 部署对话框补选支持模糊搜索与批量填入

**What to build:** 部署对话框里空名映射行的构件补选升级：
- **逐行可搜索**：每行的补选控件从原生下拉升级为 cmdk 可搜索 Combobox（与打包面板分支/构件选择器同款模糊过滤+命中高亮）
- **批量填入**：新增"批量补选"入口，一次勾选多个构件后**按顺序填入各目标的空名行**（目标顺序 → 目标内行顺序），填入后各行默认勾选；逐行覆盖仍可用（单行改选不影响其他行）
- 构件多于空名行时：多出的构件忽略并在批量入口旁提示（"已填入 N 行，M 个构件无处可填"）；空名行多于构件时照旧留空（未填行默认不勾选/按既有空行规则处理）

**语义细节：**
- 批量填入是**填充动作**，不改映射行本身（行集合仍是部署目标持久化的映射行，仅改本次部署的补选值）——与票 19 模型一致
- 具名行不参与批量填入
- 中文 i18n
