# 26: 部署时自由勾选构件——映射行降级为预设

**What to build:** 部署对话框的上传计划从"确认映射行解析结果"升级为**自由勾选**：
- 每个部署目标展示本次构建的**全部构件**，可自由勾选/取消任意构件（不再受映射行集合限制）
- **映射行降级为预设**：具名映射行对应的构件默认勾选、沿用其行目录；其他构件默认不勾选，勾选后上传到**目标默认上传目录**
- 部署目标编辑界面：恢复**默认上传目录**字段（必填）；映射行可选（可全删），行语义不变（文件名→目录，文件名仍不得重复）
- 自动连锁行为不变：仍按映射行预设解析，缺失/空名行跳过提示（自由勾选只在手动部署对话框生效）
- 仅停止/仅启动操作时计划区只读的既有行为不回退；中文 i18n

**语义细节：**
- 提交 payload 改为每目标 `entries: [{fileName, uploadDir}]`（预设条目目录=行目录，自由条目目录=目标默认目录）；后端校验 fileName ∈ 本次构建产物、目录非空，**rowId 校验移除**（映射行只在前端驱动预设）
- 旧数据迁移 v15：目标默认上传目录回填自其首个映射行的目录；映射行数据原样保留
- 「未指定」空名行预设无效果（空名行不产生预设），可在对话框内自由勾选替代——UI 上空名行不再单独展示

**Blocked by:** None（基于集成 tip 405f729）

**Status:** resolved

> 实现：迁移 v15 从首个映射行目录回填 `deployment_targets.upload_dir`（恢复为必填默认上传目录）；部署 payload 改每目标 `entries: [{fileName, uploadDir}]`（预设条目=行目录、自由条目=默认目录，rowId 校验移除，校验产物归属+目录非空）；对话框逐目标展示全部构件自由勾选、映射行作预设（票 24/25 补选 UI 移除、票 21 默认构件预选不再作用于对话框）；自动连锁按映射行预设解析不变。
